## T3 — 实机 A/B（运行期安装，**不刷机**）

> 目的：证明 G1（offload 不变量）、G4（失败无影响）、P1-1 / P1-3 / P1-5。

### 3.1 三步对照
| 步骤 | 状态 |
|---|---|
| S0 | `enabled=0`（= T0 基线） |
| S1 | `enabled=1`，名单 = 1 台客户端 |
| S2 | 恢复 `enabled=0` |

**每步采集**：非名单客户端 `ppe/bind` 计数、LAN↔WAN iperf3（3 次中位数）、名单客户端出口 IP 与分流正确性、`nft list ruleset`、`ip rule show`、`uci show firewall`、`logread` 近 5 分钟。

### 3.2 判据
| 判据 | 阈值 |
|---|---|
| G1 · 非名单客户端 `ppe/bind` 计数 | S0 与 S1 中非名单客户端的 BND 条目**必须都存在**；总计数差异只解释为名单客户端被代理的流 |
| G1 · 非名单客户端 iperf3 | S1 相对 S0 吞吐差 **≤ 2%** |
| G1 · `flow_offloading*` | S0/S1/S2 三次取值**全等** |
| I2 · fw4 未被触发 | `logread` 中 S1 期间**无** fw4/firewall 重启记录 |
| P1-3 · DNS 作用域 | **非名单客户端**解析 `www.google.com` 得**真实 IP**（绝无 `198.18.x`） |
| P1-3 · 名单客户端 DNS | CN 域名 → 真实 IP；非 CN 域名 → `198.18.x` |
| P1-1 · 名单 CN 直连保卸载 | 名单客户端访问 CN 目的时，`ppe/bind` 出现对应 BND 条目 |
| P1-4 · 依赖 | 无需新装任何 kmod 即可启动 |

### 3.3 失败演练
| 演练 | 期望 |
|---|---|
| `kill -9 sing-box` | guard 撤表撤规则；**非名单客户端 iperf3 与解析不受影响**；状态页显示 fail-open |
| 重启 `dnsmasq` | 非名单客户端解析不受影响 |
| `enabled=0` 下重启设备 | 无 nft 表、无 ip rule、无进程（G4） |
| fwmark/table 冲突注入（预先占用 `0x40`） | 拒绝启动 + 明确日志，不留半配置 |

### 3.4 NEON A/B（方案二）
| 项 | 判据 |
|---|---|
| `/proc/crypto` | 出现 `chacha20-neon`（**若不出现 ⇒ 研究判断需更正**） |
| 过 WG 的 iperf3 | 有收益 → 可考虑毕业；**无收益 → 保持 `#EXP`** |
| 过 WG 的应用延迟 | 不得劣化（SIMD 状态保存/恢复开销的代价项） |

| 项 | 判据 |
|---|---|

## T4 — 净身归还

> ⚠️ **实施期更正（2026-09-11 实机，证据见 `docs/acceptance-results/2026-09-11-proxy-ab-netstate.md` §2）**：
> 在**活体设备**上 `diff <(nft list ruleset)` **永远不可能为空**——既有 fw4 / Tailscale 链自带
> `counter packets N bytes N`，每次读取都在增长（实测 22 行差异 **100% 是计数器**，且全部落在
> 本组件不拥有的链上）。正确判据 = **归一化后比对结构**：

```sh
# 卸载并回收
/etc/init.d/xr1710g-proxy stop
apk del luci-app-xr1710g-proxy sing-box
nft delete table inet xr1710g_proxy    # 幂等兜底
# netbird：/etc/init.d/netbird stop && apk del netbird

# 归一化：抹掉易变计数器，只留结构
norm() { nft list ruleset | sed -e 's/packets [0-9]* bytes [0-9]*/packets N bytes N/g' \
                                    -e 's/counter packets N bytes N/counter/g' \
                                    -e 's/expires [0-9]*sec/Nsec/g'; }

diff <(norm < t0.nft.txt) <(norm)          # 必须为空（结构一致）
diff <(cat t0.iprule) <(ip rule show)      # 必须为空（ip rule 无计数器，可直接比）
diff <(cat t0.ucishow) <(uci show)         # 必须为空
```

**判据**：归一化后的 `nft list ruleset` + `ip rule show` + `uci show` 与 T0 **结构逐字节一致**。
（2026-09-11 实测：归一化 md5 前后相同 `a859756c13b1e540af15196a3e68bc13`，
`ip rule show` md5 相同 `34b0c094847eaddbb6dc1c5c7c055209`，Tailscale 3 条 mark 规则 + table 52 的 7 条路由零损伤。）
