## 7. 本基线的用途

1. **G1**：开关 `xr1710g_proxy` 前后，非名单客户端的 `ppe/bind` 计数与 iperf3 须与本基线无实质差异（≤2%）；
2. **G4**：全新状态下无本方案的 nft 表、无 ip rule、无进程 —— 与本基线一致；
3. **T4**：卸载后 `nft list ruleset` / `ip rule show` / `uci show` 必须与本基线**逐字节一致**；
4. **冲突检测**：table 100 与 fwmark `0x40` 在本基线均空闲。
